# Word Forge — notes for Claude

- Owner: Noah. Phone word game: 7 letters, find as many words as you can; the bank shows slots per length (or count only). Inspired by Chicktionary, no chicken theme.
- Look = Coffea Arabica / Go Dojo house style (~/Claude/Coffea, ~/Claude/GoTrainer): flat paper + ink, DM Serif Display, system sans, 1.5px ink outlines, pill buttons, no gradients/shadows/blur, light only. Tiles = flat cream top + solid ink side face.
- Edit `src/head.html` (CSS), `src/app.js`, `src/notbank.txt` (bank exclusions, still accepted as bonus words), `src/blocklist.txt` (slurs, never accepted). Then `python3 src/build.py` (~15 s) writes `app.html` (artifact https://claude.ai/artifact/EawyXnpYzfezrT8aK8X7qy, republish that file path / url), `_test.html` and `docs/` (PWA). Icons: edit `src/icon.html` (white tile, gold #efb43f border, "WF" in DM Serif Display from src/dmserif.woff2) then `zsh src/render_icons.sh` (headless Chrome renders 1024, PIL scales down; never render small sizes directly: Chrome lays out at ≥500px wide and crops them), then rebuild.
- Words: `_lists/enable1.txt` (ENABLE, everything accepted, 3–7 letters) and `_lists/en_50k.txt` (OpenSubtitles frequency; top 35k ∩ ENABLE = bank). Puzzles = 7-letter seed words (top 22k) with a 14–70 word bank, deduped by anagram, fixed shuffle (seed 7) so puzzle #n is stable. Changing lists or thresholds renumbers puzzles and invalidates saved games (boot checks the saved letters still match).
- No repeats: every started puzzle goes in S.seen and is skipped until all are used (then a new round). Variety: a new pick shares ≤5 of 7 letters with the last 25. Daily = picked fresh once per day, stored in S.daily. Points 3→1, 4→2, 5→4, 6→7, 7→12; ranks by % of bank points. State in localStorage `wordhoard-v1`.
- Testing: serve with `python3 -m http.server 8792` and open `_test.html`; drive with keydown events (letters, Enter, Backspace, space = shuffle).
- Live: https://noahwitchell.github.io/word-forge/ (public repo noahwitchell/word-forge, Pages from main /docs, push = deploy; build.py bumps the sw.js CACHE automatically). _lists/ is gitignored.
- Hints: Hint button (dock, between Delete and Shuffle) enters hint mode; tapping an unfound word reveals its next letter left to right (S.cur.hints[word] = count, S.cur.hintCount total); never the last letter. Hinted words show in Count only mode; results list hints used; "Perfect" stat only counts hint-free games.
